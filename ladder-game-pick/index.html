광고

사다리타기

10초 요약

참가자 이름과 당첨 항목을 적으면 사다리가 무작위로 그려지고, 줄이 하나씩 내려가 누가 걸렸는지 보여줍니다. 점심 내기, 발표 순서, 청소 당번을 정할 때 씁니다.

한 명이 걸리는 방식입니다

결과 칸에는 당첨 하나와 나머지 꽝이 들어갑니다. 그래서 이 도구는 여러 사람에게 각자 다른 몫을 나눠 주는 것이 아니라, 【여럿 중 한 명을 고르는 쪽】입니다. 인원은 두 명에서 여덟 명까지 되고, 이름을 안 적으시면 번호로 표시됩니다.

걸릴 확률은 인원 수로 그대로 나뉩니다. 두 명이면 2분의 1, 네 명이면 4분의 1, 여덟 명이면 8분의 1입니다. 【이름을 적은 순서는 결과와 관계없습니다.】 가로줄의 위치도, 당첨 표시가 놓이는 자리도 매판 무작위로 정해지기 때문에 첫째 칸이든 마지막 칸이든 확률은 같습니다.

사다리가 제비뽑기와 다른 점

두 방식 모두 결과는 무작위이고 확률도 같습니다. 다른 것은 과정이 보이느냐입니다. 제비뽑기는 뽑는 순간 결과가 나오지만, 사다리는 선이 가로줄을 만나 꺾이는 것을 처음부터 끝까지 따라갈 수 있습니다. 【사다리는 결과를 더 공정하게 만들지 않습니다. 대신 공정했다는 것을 눈으로 확인시켜 줍니다.】 내기에서 뒷말이 안 나오는 쪽을 원하신다면 사다리가 낫고, 빨리 끝내고 싶으시면 제비뽑기가 낫습니다.

가로줄은 다시 섞기를 누를 때마다 새로 무작위로 놓입니다. 같은 사람이 같은 자리에 있어도 다음 판은 다른 결과가 나옵니다.

사다리가 공정한지 계산해 보면

가로줄을 무작위로 충분히 넣으면 출발점과 도착점의 대응은 순열 하나가 됩니다. n명이면 가능한 대응이 n의 계승만큼입니다.

인원경우의 수와 확률
3명6가지. 특정인이 특정 결과를 받을 확률 1/3
4명24가지. 확률 1/4
5명120가지. 확률 1/5
6명720가지. 확률 1/6

【모든 결과가 같은 확률입니다.】 어느 줄에서 출발해도 같습니다. 왼쪽 끝이 유리하다는 말에는 근거가 없습니다.

다만 조건이 하나 있습니다. 가로줄이 충분히 많아야 합니다. 가로줄이 한 개뿐이면 두 줄만 바뀌고 나머지는 그대로 내려옵니다. 【가로줄 수가 적으면 출발점과 도착점이 그대로인 경우가 많아집니다.】

사다리와 제비뽑기의 진짜 차이

확률은 같습니다. 다른 것은 순서입니다.

  • 제비뽑기 — 뽑는 사람마다 남은 개수가 줄어듭니다. 앞사람이 뽑은 것을 보고 뒷사람의 확률이 달라집니다. 전체로 보면 같지만 중간에는 정보가 생깁니다
  • 사다리 — 결과가 그려지기 전에 모든 사람이 먼저 줄을 고릅니다. 누가 먼저 고르든 확률이 같습니다

【사다리는 "나중에 뽑은 사람이 유리하다"는 다툼이 생기지 않습니다.】 고르는 시점에 아무 정보도 없기 때문입니다.

그리고 결과가 한 번에 드러납니다. 제비뽑기는 한 장씩 열리면서 긴장이 이어지는데, 사다리는 선을 따라가면 전원의 결과가 동시에 정해집니다. 【벌칙을 정할 때 사다리를 쓰는 이유가 이것입니다.】

다시 돌리면 안 되는 이유

결과가 나온 뒤 다시 돌리면 확률이 달라집니다. 마음에 안 드는 결과가 나올 때만 다시 돌리면, 여러 번 시도하는 사람에게 유리한 결과가 나올 때까지 뽑는 셈이 됩니다.

【한 번 돌리기로 정하는 것까지가 공정함의 조건입니다.】 돌리기 전에 몇 번 돌릴지 정해 두십시오.

자주 묻는 질문

결과가 미리 정해져 있나요?
사다리는 매번 무작위로 새로 그려집니다. 가로줄과 당첨 자리가 모두 난수로 정해지고, 사람이 고르는 단계는 없습니다.
몇 명까지 되나요?
두 명부터 여덟 명까지 됩니다.
당첨 확률이 얼마인가요?
인원 수로 나눈 만큼입니다. 네 명이면 4분의 1, 여덟 명이면 8분의 1입니다.
한 번에 여러 명을 뽑을 수 있나요?
당첨은 한 자리입니다. 여러 명을 정하셔야 한다면 뽑힌 사람을 빼고 다시 돌리시면 됩니다.
이름을 먼저 적은 사람이 유리한가요?
아닙니다. 가로줄과 당첨 자리가 매판 무작위라 적은 순서와 상관없이 확률이 같습니다.
사다리는 정말 공정한가요
가로줄이 충분하면 모든 대응이 같은 확률입니다. n명이면 가능한 대응이 n의 계승만큼이고(4명 24가지, 6명 720가지) 특정인이 특정 결과를 받을 확률은 1/n입니다.
왼쪽 끝이 유리한가요
유리하지 않습니다. 어느 줄에서 출발해도 확률이 같습니다. 다만 가로줄 수가 적으면 출발점과 도착점이 그대로인 경우가 많아지므로 가로줄이 충분해야 합니다.
제비뽑기와 확률이 다른가요
확률은 같습니다. 다른 것은 순서입니다. 제비뽑기는 앞사람이 뽑은 것을 보고 뒷사람의 정보가 달라지는데, 사다리는 모두가 결과를 모르는 상태에서 줄을 고릅니다.
왜 벌칙 정할 때 사다리를 쓰나요
고르는 시점에 아무 정보가 없어 "나중에 뽑은 사람이 유리하다"는 다툼이 생기지 않고, 선을 따라가면 전원의 결과가 동시에 정해집니다.
결과가 마음에 안 들면 다시 돌려도 되나요
결과를 보고 나서 다시 돌릴지 정하면 규칙이 아니라 협상이 됩니다. 돌리기 전에 몇 번 돌릴지 정해 두십시오.
